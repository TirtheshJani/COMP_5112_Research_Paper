# COMP 5112 context pack: everything so far (as of 11 November 2026, 16:40 Toronto)

This folder holds the full context of the COMP 5112 research project "Which Way Is Up?", from the first assignment to the Reachy Mini jigsaw idea Aaron Williams suggested on 11 November. It is written so that a new chat, a Claude Science project, NotebookLM, or TJ himself can pick up the work without the conversation history. Every number in it was taken from the paper, the results files or the project docs, not from memory.

## Status in one paragraph

The research paper (draft 3, 28 pages, LIPIcs) answers the poster's question: orientation and error detection compete in binary position tori. Distance 2 halves the counting ceiling, tori lose more (exact 3 x 3 maximum 36 cells against at least 85 for orientation alone), the extra cost appears when the pattern must close on itself, and 256 x 256 strong-form tori with 5 x 5 windows exist. A 14-slide talk deck, an 84-page study guide, a verified reading list and G2 prep notes for the meeting with Aaron are done. On 11 November Aaron suggested, for this same paper and presentation, a two-sided jigsaw puzzle with a binary pattern on the back that a Reachy Mini reads to tell you where a held-up piece goes. TJ wants to do it if it is doable. Planning that is the next step.
